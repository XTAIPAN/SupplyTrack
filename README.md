# SupplyTrack
A MySQL based logistics &amp; supply chain management system managing procurement, inventory, sales, shipments, and warehouse data across 10 relational tables. Features real world SQL queries (joins, CTEs, window functions, procedures) replicating reporting and decision-making tools used by logistics and supply chain teams in real companies.
SupplyTrack is a relational database system built in MySQL to manage and analyze end-to-end supply chain operations for a logistics-driven business. The system tracks the complete product lifecycle from supplier procurement and inventory management to customer sales, order shipment, and warehouse operations across 10 interconnected tables. The project uses SQL queries (including joins, aggregations, window functions, CTEs, and stored procedures) to generate real-time business insights such as sales trends, supplier delivery performance, inventory reorder alerts, freight cost analysis, warehouse-wise expense tracking, and overall profitability replicating the kind of reporting and decision-making tools used by logistics and supply chain teams in real companies.
